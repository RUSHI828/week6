# Task 3: Student Management System

## Description

A Python-based Student Management System that allows users to manage student records through a menu-driven interface.

## Features

* Add student details
* Display all students
* Search for a student
* Update student marks
* Delete student records
* Save student records using JSON file handling
* Handle invalid inputs and errors

## Technologies Used

* Python
* JSON

## Python Concepts Used

* Variables and data types
* Input and output
* Conditional statements
* Loops
* Functions and methods
* Lists
* File handling
* Exception handling
* Object-Oriented Programming
* Classes and objects
* Inheritance
* Encapsulation
* Abstraction
* Polymorphism

## How to Run

1. Install Python.
2. Open the project folder in VS Code.
3. Run `Task 3.py`.
4. Follow the menu options to manage student records.
