## 💻 Basic Git Commands

```bash
# Configure Git
git config --global user.name "Rushikesh Jadhav"
git config --global user.email "YOUR_EMAIL"

# Initialize the repository
git init

# Check repository status
git status

# Add files
git add .

# Commit changes
git commit -m "Initial commit"

# Connect to GitHub
git remote add origin https://github.com/RUSHI828/YOUR_REPOSITORY.git

# Rename the branch
git branch -M main

# Upload the project
git push -u origin main
```

Replace `YOUR_EMAIL` with your GitHub email and `YOUR_REPOSITORY` with your actual repository name.
